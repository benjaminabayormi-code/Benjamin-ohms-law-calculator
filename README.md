## 1. What it does
This Python program calculates voltage, current, resistance, and electrical power using Ohm's Law and standard electrical power formulas. It also allows users to view their calculation history and checks calculated power against a component's stated maximum power rating.

## 2. How to run it
1. Install Python 3 or open the Pydroid 3 app on an Android phone.
2. Open the file named `ohms_law_calculator.py`.
3. Run the program.
4. Select an option from the menu and enter the requested values.

## 4. My own twist
