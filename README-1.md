**Author:** Fade Benjamin Olajide\

## Project Description

This Python project is a simple calculator for solving common electrical
calculations using Ohm's Law and electrical power formulas.

It helps users calculate voltage, current, resistance, and electrical
power when the required values are provided.

## Formulas Used

### Ohm's Law

-   Voltage: `V = I × R`
-   Current: `I = V ÷ R`
-   Resistance: `R = V ÷ I`

### Electrical Power

-   Power: `P = V × I`
-   Power: `P = I² × R`
-   Power: `P = V² ÷ R`

Where:

-   `V` = Voltage (volts)
-   `I` = Current (amperes)
-   `R` = Resistance (ohms)
-   `P` = Power (watts)

## How to Run

1.  Make sure Python 3 is installed.

2.  Download `ohms_law_calculator.py`.

3.  Open a terminal or command prompt in the folder containing the file.

4.  Run:

    ``` bash
    python ohms_law_calculator.py
    ```
